% ==========================================================
% PART C — EQUIVALENT EXPRESSIONS CHECKS
% ==========================================================
\begin{tcolorbox}[colback=black!10]
\large\textcolor{black}{\textbf{Equivalent Expressions Checks}}
\end{tcolorbox}

\noindent
Determine if the given pairs of expressions are equivalent by evaluating them for a specific value.

\vspace{3mm}

\begin{enumerate}[itemsep=2.2cm, leftmargin=0.6cm]

\item Are $3(x + 2)$ and $3x + 6$ equivalent? Evaluate both for $x = 3$.

\vspace{2cm}

\item Are $2(y - 3)$ and $2y - 3$ equivalent? Evaluate both for $y = 5$.

\vspace{2cm}

\item Are $4a + 3a$ and $7a^2$ equivalent? Evaluate both for $a = 2$.

\vspace{2cm}

\end{enumerate}

\begin{tcolorbox}[colback=black!10]
\large\textcolor{black}{\textbf{Basic Word Problems}}
\end{tcolorbox}

\noindent
Write and simplify algebraic expressions for the following scenarios.

\vspace{3mm}

\begin{enumerate}[itemsep=2.2cm, leftmargin=0.6cm]

\item Write an expression for the total weight of 4 boxes that weigh $w$ kg each and 1 box that weighs $10$ kg. Simplify it.

\vspace{2.2cm}

\item A rectangular field has length $l$ yards and width 5 yards. Write an expression for its perimeter. Simplify it.

\vspace{2.2cm}

\item A student buys $x$ apples for \$2 each and $x$ bananas for \$1.50 each. Write an expression for the total cost. Simplify it by combining like terms.

\vspace{2.2cm}

\end{enumerate}
