\vspace{3mm}
\noindent
\begin{itemize}
    \item An angle is measured in **degrees ($^\circ$)** using a **protractor**.
    \item A straight angle is $180^\circ$. A right angle is $90^\circ$.
    \item Angles can be added together to find a larger angle.
\end{itemize}

\begin{center}
\begin{tikzpicture}[scale=1.2]
\draw[thick, ->] (0,0) -- (3,0) node[right] {A};
\draw[thick, ->] (0,0) -- (2.12, 2.12) node[above right] {B};
\draw[thick, ->] (0,0) -- (0, 2.5) node[above] {C};
\draw[domain=0:45, ->, red] plot ({0.6*cos(\x)}, {0.6*sin(\x)});
\draw[domain=45:90, ->, blue] plot ({0.8*cos(\x)}, {0.8*sin(\x)});
\node[red] at (0.8, 0.3) {$45^\circ$};
\node[blue] at (0.5, 1.0) {$45^\circ$};
\end{tikzpicture}
\end{center}
Here, $\angle AOC = \angle AOB + \angle BOC = 45^\circ + 45^\circ = 90^\circ$.
