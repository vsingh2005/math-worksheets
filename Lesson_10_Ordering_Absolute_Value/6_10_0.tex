% SECTION 1: COMPARING, ORDERING, AND ABSOLUTE VALUE
% ==========================================================
\begin{tcolorbox}[colback=customteal!20]
    \large\textcolor{black}{\textbf{Comparing, Ordering, and Absolute Value (Foundation)}}
\end{tcolorbox}

\vspace{3mm}

\noindent
1. \textbf{Comparing:} On a number line, values increase from left to right. $-5 < -2$ because $-5$ is to the left of $-2$. \\
2. \textbf{Absolute Value:} The distance of a number from 0 on a number line, denoted as $|x|$. Absolute value is always positive or zero. Example: $|-5| = 5$, and $|5| = 5$. \\
3. \textbf{Order vs. Absolute Value:} A number with a smaller value can have a larger absolute value. For instance, $-10 < -2$, but $|-10| > |-2|$ (meaning a debt of \$10$ is larger than a debt of \$2$).

\vspace{4mm}
