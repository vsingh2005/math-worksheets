\begin{tcolorbox}[colback=customteal!20]
    \large\textcolor{black}{\textbf{Foundation: Systems of Equations}}
\end{tcolorbox}

\vspace{3mm}

\noindent
A \textbf{system of linear equations} is a set of two or more linear equations that contain the same variables. The \textbf{solution} to a system is the coordinate $(x, y)$ that makes \textit{both} equations true at the same time.

\begin{itemize}
    \item \textbf{Graphing Method:} If you graph both lines on the same coordinate plane, the solution is the exact point where the two lines \textbf{intersect}.
    \item \textbf{Number of Solutions:} 
    \begin{itemize}
        \item \textbf{One Solution:} The lines intersect at exactly one point (different slopes).
        \item \textbf{No Solution:} The lines are parallel and never intersect (same slope, different $y$-intercepts).
        \item \textbf{Infinite Solutions:} The lines are exactly the same (same slope, same $y$-intercept).
    \end{itemize}
\end{itemize}

\vspace{4mm}

% VISUAL REPRESENTATION

\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Visual Representation: Finding the Intersection}

\medskip

\begin{center}
\begin{tikzpicture}[scale=0.8]
% Grid
\draw[step=1cm,gray!30,very thin] (-3,-3) grid (5,5);
\draw[thick,->] (-3.5,0) -- (5.5,0) node[right] {$x$};
\draw[thick,->] (0,-3.5) -- (0,5.5) node[above] {$y$};

% Line 1: y = x + 1
\draw[thick, blue, <->] (-3, -2) -- (4, 5) node[right] {$y = x + 1$};

% Line 2: y = -2x + 4
\draw[thick, red, <->] (-0.5, 5) -- (3.5, -3) node[right] {$y = -2x + 4$};

% Intersection
\filldraw[black] (1,2) circle (3pt) node[above right, font=\bfseries] {$(1, 2)$};

\end{tikzpicture}
\end{center}

\medskip
\begin{itemize}
    \item The blue line is $y = x + 1$.
    \item The red line is $y = -2x + 4$.
    \item They intersect at the point $(1, 2)$. This means $x=1$ and $y=2$ is the only pair of numbers that works in both equations.
\end{itemize}

\end{tcolorbox}

\begin{tcolorbox}[colback=customteal!20]
\large\textcolor{black}{\textbf{Solving by Graphing}}
\end{tcolorbox}

\noindent
To solve by graphing, you must graph both lines accurately using their slope and $y$-intercept.

\vspace{3mm}

\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Worked Example 1: Graphing a System}

\medskip

\textbf{Problem:} Solve the system of equations by graphing:
\begin{align*}
    y &= 2x - 3 \\
    y &= -x + 3
\end{align*}

\medskip

\textbf{Solution:}
\begin{itemize}
    \item \textbf{Step 1 (Graph Line 1):} For $y = 2x - 3$, start at $b = -3$ on the $y$-axis. The slope is $2$, so go up $2$ and right $1$.
    \item \textbf{Step 2 (Graph Line 2):} For $y = -x + 3$, start at $b = 3$ on the $y$-axis. The slope is $-1$, so go down $1$ and right $1$.
    \item \textbf{Step 3 (Find Intersection):} By continuing the slope pattern, both lines hit the point $(2, 1)$.
    \item \textbf{Step 4 (Check):} Plug $(2,1)$ into both equations. 
    $1 = 2(2) - 3 \rightarrow 1 = 1$ (True). 
    $1 = -(2) + 3 \rightarrow 1 = 1$ (True).
\end{itemize}

\end{tcolorbox}
