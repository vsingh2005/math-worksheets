\begin{tcolorbox}[colback=customteal!20]
    \large\textcolor{black}{\textbf{Foundation: Slope-Intercept Form}}
\end{tcolorbox}

\vspace{3mm}

\noindent
Linear equations can be written in a very useful format called \textbf{slope-intercept form}:
\[ y = mx + b \]

\begin{itemize}
    \item \textbf{$m$ (Slope):} The steepness of the line, or the constant rate of change ($\dfrac{\text{Rise}}{\text{Run}}$).
    \item \textbf{$b$ ($y$-intercept):} The point where the line crosses the $y$-axis. This is the starting value when $x = 0$. The coordinate is $(0, b)$.
\end{itemize}

\vspace{4mm}

% ==========================================================
% VISUAL REPRESENTATION
% ==========================================================
\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Visual Representation: Graphing from $y = mx + b$}

\medskip

\begin{center}
\begin{tikzpicture}[scale=0.8]
% Grid
\draw[step=1cm,gray!30,very thin] (-3,-2) grid (5,6);
\draw[thick,->] (-3.5,0) -- (5.5,0) node[right] {$x$};
\draw[thick,->] (0,-2.5) -- (0,6.5) node[above] {$y$};

% Line y = 2x + 1
\draw[thick, blue, <->] (-1.5, -2) -- (2.5, 6);

% y-intercept
\filldraw[red] (0,1) circle (3pt) node[above left] {$b=1$};

% Slope triangle
\draw[thick, dashed, green!70!black] (0,1) -- (1,1) node[midway, below] {$+1$};
\draw[thick, dashed, green!70!black] (1,1) -- (1,3) node[midway, right] {$+2$};
\filldraw[blue] (1,3) circle (3pt);

\end{tikzpicture}
\end{center}

\medskip
\begin{itemize}
    \item The line crosses the $y$-axis at $1$. So, the $y$-intercept is $b = 1$.
    \item To get to the next point, we go \textbf{up 2} and \textbf{right 1}. The slope is $m = \dfrac{2}{1} = 2$.
    \item The equation of this line is $y = 2x + 1$.
\end{itemize}

\end{tcolorbox}

\begin{tcolorbox}[colback=customteal!20]
\large\textcolor{black}{\textbf{Writing Equations}}
\end{tcolorbox}

\noindent
We can find the equation of a line if we are given its slope and $y$-intercept, or if we can extract them from a graph or two points.

\vspace{3mm}

\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Worked Example 1: From a Graph}

\medskip

\textbf{Problem:} Write the equation of a line that crosses the $y$-axis at $-3$ and has a slope of $-\dfrac{1}{4}$.

\medskip

\textbf{Solution:}
\begin{itemize}
    \item \textbf{Step 1 (Identify $b$):} The line crosses the $y$-axis at $-3$, so $b = -3$.
    \item \textbf{Step 2 (Identify $m$):} The slope is $-\dfrac{1}{4}$, so $m = -\dfrac{1}{4}$.
    \item \textbf{Step 3 (Write equation):} Plug them into $y = mx + b$. 
    \item $y = -\dfrac{1}{4}x - 3$.
\end{itemize}

\end{tcolorbox}

\vspace{4mm}
