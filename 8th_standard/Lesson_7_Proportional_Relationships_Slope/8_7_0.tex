\begin{tcolorbox}[colback=customteal!20]
    \large\textcolor{black}{\textbf{Foundation: Proportions \& Slope}}
\end{tcolorbox}

\vspace{3mm}

\noindent
A \textbf{proportional relationship} is a special kind of linear relationship where the ratio of $y$ to $x$ is constant for all values. The graph of a proportional relationship is always a straight line that passes through the \textbf{origin $(0,0)$}.

\begin{itemize}
    \item \textbf{Unit Rate and Slope:} In a proportional relationship, the \textbf{unit rate} (the constant of proportionality) is exactly the same as the \textbf{slope} of the line.
    \item \textbf{Equation:} The equation of a proportional relationship is written as $y = mx$, where $m$ is the slope.
\end{itemize}

\vspace{4mm}

% ==========================================================
% VISUAL REPRESENTATION
% ==========================================================
\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Visual Representation: Graphing $y = 3x$}

\medskip

\begin{center}
\begin{tikzpicture}[scale=0.6]
% Grid
\draw[step=1cm,gray!30,very thin] (-1,-1) grid (5,10);
\draw[thick,->] (-1.5,0) -- (5.5,0) node[right] {$x$ (Hours)};
\draw[thick,->] (0,-1.5) -- (0,10.5) node[above] {$y$ (Miles)};

% Line
\draw[thick, blue, ->] (0, 0) -- (3.33, 10);

% Points
\filldraw[blue] (0,0) circle (3pt) node[below right, black] {$(0,0)$};
\filldraw[blue] (1,3) circle (3pt) node[below right, black] {$(1,3)$};
\filldraw[blue] (2,6) circle (3pt) node[below right, black] {$(2,6)$};
\filldraw[blue] (3,9) circle (3pt) node[below right, black] {$(3,9)$};

\end{tikzpicture}
\end{center}

\medskip
\begin{itemize}
    \item This graph passes through $(0,0)$. This means if you travel for $0$ hours, you go $0$ miles.
    \item The unit rate is $3$ miles per hour.
    \item The slope ($\dfrac{\text{Rise}}{\text{Run}}$) is $\dfrac{3}{1} = 3$.
    \item The equation is $y = 3x$.
\end{itemize}

\end{tcolorbox}

\begin{tcolorbox}[colback=customteal!20]
\large\textcolor{black}{\textbf{Comparing Proportional Relationships}}
\end{tcolorbox}

\noindent
We can compare proportional relationships represented in different ways (graphs, tables, equations, words) by finding the slope (unit rate) of each.

\vspace{3mm}

\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Worked Example 1: Comparing Speeds}

\medskip

\textbf{Problem:} Car A's distance is given by the equation $y = 55x$ (where $x$ is hours and $y$ is miles). Car B's distance is shown in a table where $(2\text{ hours}) = 100\text{ miles}$. Which car is faster?

\medskip

\textbf{Solution:}
\begin{itemize}
    \item \textbf{Step 1 (Find speed of Car A):} The equation is $y = 55x$. The slope (unit rate) is $55$. So Car A travels $55$ mph.
    \item \textbf{Step 2 (Find speed of Car B):} The table gives $(2, 100)$. Because it's a proportional relationship (distance traveled), it passes through $(0,0)$. 
    \item $m = \dfrac{100 - 0}{2 - 0} = \dfrac{100}{2} = 50$. So Car B travels $50$ mph.
    \item \textbf{Step 3 (Compare):} $55 > 50$, so Car A is faster.
\end{itemize}

\end{tcolorbox}
