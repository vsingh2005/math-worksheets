\begin{tcolorbox}[colback=customteal!20]
    \large\textcolor{black}{\textbf{Foundation: Slope \& Similar Triangles}}
\end{tcolorbox}

\vspace{3mm}

\noindent
The \textbf{slope} of a line describes its steepness. We calculate slope as the ratio of the vertical change (``rise'') to the horizontal change (``run'') between any two points on the line. 

\begin{itemize}
    \item \textbf{Slope ($m$):} $m = \dfrac{\text{Rise}}{\text{Run}} = \dfrac{\text{Change in } y}{\text{Change in } x} = \dfrac{y_2 - y_1}{x_2 - x_1}$
    \item \textbf{Similar Triangles on a Line:} No matter which two points you pick on a straight line, the "slope triangles" you draw between them are \textbf{similar}. This means the ratio of their sides (rise/run) will always simplify to the exact same number. The slope is constant!
\end{itemize}

\vspace{4mm}

\draw[thick, green!70!black] (3,1.5) -- (7,1.5) node[midway, below] {$4$} -- (7,3.5) node[midway, right] {$2$} -- cycle;

\end{tikzpicture}
\end{center}

\medskip
\begin{itemize}
    \item Triangle $A \rightarrow B$: Rise = $1$, Run = $2$. Slope = $\dfrac{1}{2}$.
    \item Triangle $B \rightarrow C$: Rise = $2$, Run = $4$. Slope = $\dfrac{2}{4} = \dfrac{1}{2}$.
    \item The triangles are similar, so the slope is always $\dfrac{1}{2}$!
\end{itemize}

\begin{tcolorbox}[colback=customteal!20]
\large\textcolor{black}{\textbf{Calculating Slope}}
\end{tcolorbox}

\noindent
Let's calculate slope using the formula and confirm it works with any points.

\vspace{3mm}

\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Worked Example 1: Finding Slope from Points}

\medskip

\textbf{Problem:} Find the slope of the line passing through $(-2, 1)$ and $(4, 4)$.

\medskip

\textbf{Solution:}
\begin{itemize}
    \item \textbf{Step 1 (Identify Coordinates):} $(x_1, y_1) = (-2, 1)$ and $(x_2, y_2) = (4, 4)$.
    \item \textbf{Step 2 (Apply Formula):} $m = \dfrac{y_2 - y_1}{x_2 - x_1}$
    \item $m = \dfrac{4 - 1}{4 - (-2)}$
    \item $m = \dfrac{3}{4 + 2} = \dfrac{3}{6}$
    \item \textbf{Step 3 (Simplify):} $m = \dfrac{1}{2}$
\end{itemize}

\end{tcolorbox}
