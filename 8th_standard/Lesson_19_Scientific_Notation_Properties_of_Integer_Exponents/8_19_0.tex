\begin{tcolorbox}[colback=customteal!20]
    \large\textcolor{black}{\textbf{Foundation: The Five Exponent Rules}}
\end{tcolorbox}

\vspace{3mm}

\noindent
An \textbf{exponent} tells you how many times to multiply the base by itself. E.g., $x^3 = x \cdot x \cdot x$. When we do math with exponents, we have five major rules that serve as shortcuts!

\begin{itemize}
    \item \textbf{1. Multiplication Rule:} When multiplying with the same base, ADD the exponents. 
    \[ x^a \cdot x^b = x^{a+b} \]
    \item \textbf{2. Division Rule:} When dividing with the same base, SUBTRACT the exponents.
    \[ \dfrac{x^a}{x^b} = x^{a-b} \]
    \item \textbf{3. Power of a Power Rule:} When raising a power to another power, MULTIPLY the exponents.
    \[ (x^a)^b = x^{a \cdot b} \]
    \item \textbf{4. Zero Exponent Rule:} Anything to the power of zero equals $1$.
    \[ x^0 = 1 \]
    \item \textbf{5. Negative Exponent Rule:} A negative exponent means to flip it to the denominator (or numerator) to make it positive.
    \[ x^{-a} = \dfrac{1}{x^a} \]
\end{itemize}

\vspace{4mm}

% ==========================================================
% WORKED EXAMPLES
% ==========================================================
\begin{tcolorbox}[colback=customteal!20]
\large\textcolor{black}{\textbf{Applying the Rules}}
\end{tcolorbox}

\noindent
If you forget a rule, expand the expression! $x^2 \cdot x^3 = (x \cdot x) \cdot (x \cdot x \cdot x) = x^5$. 

\vspace{3mm}

\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Worked Example 1: Simplifying Expressions}

\medskip

\textbf{Problem A:} Simplify $y^4 \cdot y^{-2}$

\medskip

\textbf{Solution A:}
\begin{itemize}
    \item Use the Multiplication Rule (add exponents).
    \item $y^{4 + (-2)} = y^2$
\end{itemize}

\medskip
\hrule
\medskip

\textbf{Problem B:} Simplify $\dfrac{4^5}{4^8}$ and write the answer with a positive exponent.

\medskip

\textbf{Solution B:}
\begin{itemize}
    \item Use the Division Rule (subtract exponents).
    \item $4^{5 - 8} = 4^{-3}$
    \item Use the Negative Exponent Rule to flip it.
    \item $\dfrac{1}{4^3}$
\end{itemize}

\end{tcolorbox}
