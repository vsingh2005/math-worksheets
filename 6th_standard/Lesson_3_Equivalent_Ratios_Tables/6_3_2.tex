\vspace{3mm}

\noindent
Equivalent ratios have the same value. Create them by multiplying or dividing both parts by the same number. Ratio tables organize equivalent ratios in rows and columns to show patterns.

Create tables showing the first 5 values for each:

\hline

\vspace{1cm}

Which paint has a higher ratio of red to blue? \blanklong
