\large\textcolor{black}{\textbf{Instruction: The Probability Scale}}
\end{tcolorbox}

\vspace{3mm}

\noindent
\textbf{Probability} is a measure of how likely an event is to happen. It is always a number between $0$ and $1$ (or $0\%$ to $100\%$).
\begin{itemize}
    \item \textbf{0 (or 0\%):} Impossible (will never happen).
    \item \textbf{0.25 (or 25\%):} Unlikely.
    \item \textbf{0.5 (or 50\%):} Equally likely as unlikely (a 50/50 chance, like flipping a coin).
    \item \textbf{0.75 (or 75\%):} Likely.
    \item \textbf{1 (or 100\%):} Certain (it will absolutely happen).
\end{itemize}

\vspace{2mm}
\noindent
\textbf{How to calculate Theoretical Probability:}
\[ P(\text{event}) = \dfrac{\text{Number of Favorable Outcomes}}{\text{Total Number of Possible Outcomes}} \]
