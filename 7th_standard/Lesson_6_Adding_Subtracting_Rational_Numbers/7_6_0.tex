\begin{tcolorbox}[colback=customteal!20]
    \large\textcolor{black}{\textbf{Adding \& Subtracting Rational Numbers}}
\end{tcolorbox}

\vspace{3mm}

\noindent
A \textbf{rational number} is any number that can be written as a fraction $\frac{a}{b}$, where $a$ and $b$ are integers and $b \neq 0$. This includes positive and negative fractions, decimals, and integers.

\begin{itemize}
    \item \textbf{Adding with Same Signs:} Add their absolute values. The sum has the same sign as the addends.
    \item \textbf{Adding with Different Signs:} Subtract the smaller absolute value from the larger absolute value. The sum has the sign of the number with the larger absolute value.
    \item \textbf{Subtracting Rational Numbers:} Add the additive inverse (opposite) of the number being subtracted: $a - b = a + (-b)$.
\end{itemize}

\vspace{4mm}

% VISUAL REPRESENTATION: NUMBER LINE

\textbf{Visualizing on a Number Line}

\medskip

\noindent
To model rational number operations on a number line:
\begin{enumerate}
    \item Always start at $0$.
    \item Move \textbf{right} for positive numbers, and \textbf{left} for negative numbers.
\end{enumerate}

\medskip

\noindent
\textbf{Example:} Model and evaluate $-1.5 + 2.5$

\vspace{3mm}

\begin{center}
\begin{tikzpicture}[x=1.8cm, y=1cm]
  % Draw number line axis
  \draw[latex-latex, thick] (-2.5,0) -- (2.5,0);
  
  % Draw ticks and labels
  \foreach \x in {-2,-1,0,1,2} {
    \draw (\x, 0.1) -- (\x, -0.1) node[below=2pt] {\small\x};
  }
  \foreach \x in {-1.5,-0.5,0.5,1.5} {
    \draw (\x, 0.05) -- (\x, -0.05) node[below=2pt] {\tiny\x};
  }
  
  % Arrow 1: 0 to -1.5
  \draw[red, -{Latex[length=2mm]}, thick] (0, 0.4) -- (-1.5, 0.4);
  \node[red, above] at (-0.75, 0.4) {\small $-1.5$};
  
  % Arrow 2: -1.5 to 1.0
  \draw[blue, -{Latex[length=2mm]}, thick] (-1.5, 0.9) -- (1, 0.9);
  \node[blue, above] at (-0.25, 0.9) {\small $+2.5$};
  
  % Final point marker
  \filldraw[black] (1,0) circle (2.5pt);
  \draw[dashed, black!60] (1,0) -- (1,0.9);
  \node[above right] at (1, 0.1) {\textbf{End at 1}};
\end{tikzpicture}
\end{center}

\medskip

\noindent
\textbf{Result:} $-1.5 + 2.5 = 1$

\begin{tcolorbox}[colback=customteal!20]
\large\textcolor{black}{\textbf{Real-World Contexts}}
\end{tcolorbox}

\noindent
Rational numbers are essential for describing real-world situations involving changes above and below a reference point ($0$).

\begin{itemize}
    \item \textbf{Temperature:} Above zero is positive ($+15.5^\circ\text{C}$), below zero is negative ($-4.2^\circ\text{C}$).
    \item \textbf{Elevation:} Above sea level is positive ($+250\text{ ft}$), below sea level is negative ($-12\text{ ft}$).
    \item \textbf{Finance:} Money earned/saved is positive ($+\$50.00$), debt or spent money is negative ($-\$25.50$).
\end{itemize}

\vspace{3mm}

\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Worked Example: Elevation Change}

\medskip

\textbf{Problem:} A researcher in a submarine begins at an elevation of $-45.5$ meters (below sea level). The submarine then descends another $20\dfrac{1}{4}$ meters. What is the submarine's new elevation?

\medskip

\noindent
\textbf{Solution:}
\begin{enumerate}
    \item Represent the initial elevation as a negative decimal: $-45.5$
    \item Represent the descent as subtracting a positive value or adding a negative value. Convert $20\dfrac{1}{4}$ to decimal: $20.25$
    \item Set up the equation:
    \[
    -45.5 - 20.25 = -45.5 + (-20.25)
    \]
    \item Add the absolute values and keep the negative sign:
    \[
    45.5 + 20.25 = 65.75 \implies -65.75
    \]
\end{enumerate}

\noindent
\textbf{Answer:} The submarine's new elevation is $-65.75$ meters (or $65.75$ meters below sea level).

\end{tcolorbox}
