\large\textcolor{black}{\textbf{Part A: Using Tables to Find Probability}}
\end{tcolorbox}

\vspace{3mm}

\noindent
To find the probability of a compound event, count the number of winning outcomes in your sample space and divide by the total number of outcomes.

\vspace{0.5cm}

\begin{enumerate}[itemsep=\fill, leftmargin=0.6cm]

\item You roll two standard 6-sided dice and add the numbers together. 
\begin{itemize}
    \item Create a $6 \times 6$ table showing all the possible SUMS you can get.
    \item What is the total number of outcomes? \blank
    \item What is $P(\text{Sum of 7})$? \blank
    \item What is $P(\text{Sum greater than 10})$? \blank
\end{itemize}

\end{enumerate}

\vspace{7cm}

% ==========================================================
% PART B - MULTIPLICATION RULE
% ==========================================================
\begin{tcolorbox}[colback=customteal!20]
\large\textcolor{black}{\textbf{Part B: The Fundamental Counting Principle}}
\end{tcolorbox}

\noindent
You can find the TOTAL number of outcomes by simply multiplying the number of options for each event.

\vspace{0.5cm}

\begin{enumerate}[itemsep=\fill, leftmargin=0.6cm, resume]

\item A car dealership allows you to customize a car. You can choose from $4$ exterior colors, $3$ interior colors, and $2$ engine types. Use multiplication to find the total number of different car combinations possible.

\end{enumerate}
