\begin{tcolorbox}[colback=customteal!20]
\large\textcolor{black}{\textbf{Instruction: How to Solve Two-Step Equations}}
\end{tcolorbox}

\vspace{3mm}

\noindent
To solve a two-step equation like $px + q = r$, you must isolate the variable $x$ by using inverse operations. Think of it as doing PEMDAS backwards!

\vspace{2mm}
\noindent
\textbf{Step 1: Undo Addition or Subtraction.}\\
\textbf{Step 2: Undo Multiplication or Division.}

\vspace{3mm}
\noindent
\textbf{Example 1:} $3x + 5 = 17$
\begin{itemize}
    \item \textbf{Step 1:} Subtract 5 from both sides. $\rightarrow 3x = 12$
    \item \textbf{Step 2:} Divide by 3 on both sides. $\rightarrow x = 4$
\end{itemize}

\vspace{3mm}
\noindent
\textbf{Example 2:} $\dfrac{x}{4} - 2 = 6$
\begin{itemize}
    \item \textbf{Step 1:} Add 2 to both sides. $\rightarrow \dfrac{x}{4} = 8$
    \item \textbf{Step 2:} Multiply both sides by 4. $\rightarrow x = 32$
\end{itemize}
