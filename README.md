# Math Worksheets Generator

Automated arithmetic worksheet generator and educational portal created for STEM Studio Chicago to dynamically produce customizable math exercises for K-8 students.

## Overview

Designed to streamline curriculum preparation for instructors at STEM Studio, this system programmatically generates randomized arithmetic and problem-solving worksheets with customizable difficulty constraints and automated answer key generation.

## Features

- **Dynamic Problem Synthesis**: Generates targeted arithmetic (addition, subtraction, multiplication, division, fractions) within configurable number bounds.
- **Automated Answer Keys**: Produces matched solution sheets for instructor verification.
- **Web Portal Integration**: Web-ready layout templates for direct PDF export and printing.

## Tech Stack

- **Languages**: Python, HTML/CSS, JavaScript
- **Integration**: WordPress / Web Templates
