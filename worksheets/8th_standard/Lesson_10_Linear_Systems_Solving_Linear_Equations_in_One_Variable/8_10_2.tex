\vspace{3mm}

\begin{enumerate}[itemsep=4.2cm, leftmargin=0.6cm]
\item [label=\alph*., itemsep=0.2em]
\item Distribute to remove parentheses.
\item Combine like terms on each side of the equation.
\item Move all variable terms to one side and constant terms to the other side using addition/subtraction.
\item Isolate the variable using multiplication/division.
\item Solve for $x$: $4x - 7 = 2x + 9$
\vspace{2cm} % Space for work
\item Solve for $y$: $5(y + 2) = 3y - 6$
\vspace{2cm}
\item Solve for $w$: $-2(w - 4) = -2w + 8$. State the number of solutions and explain your reasoning.
\vspace{2cm}
\item A cell phone plan costs $\$30$ per month plus $\$0.10$ per text message. If your bill for one month was $\$45$, how many text messages did you send? Set up an equation and solve.
\vspace{2cm}
\item The sum of three consecutive integers is $72$. Write an equation to represent this situation and find the integers.
\vspace{2cm}
\end{enumerate}

\vspace{2cm}
\item Write an equation that has NO solution. Explain the characteristics of such an equation.
\vspace{2cm}
\item Write an equation that has infinitely many solutions. Explain the characteristics of such an equation.
\vspace{2cm}
\item % Continue numbering
\item Two competing health clubs have different payment plans. Club A charges a $\$40$ sign-up fee plus $\$10$ per month. Club B has no sign-up fee but charges $\$18$ per month.
    \begin{enumerate}[label=\alph*.]
\item Set up an equation to find out after how many months the total cost will be the same.
\item Solve the equation to find the number of months.
\end{enumerate}
