\begin{tcolorbox}[colback=customteal!20]
    \large\textcolor{black}{\textbf{Foundation: Reading Scatter Plots}}
\end{tcolorbox}

\vspace{3mm}

\noindent
A \textbf{scatter plot} shows the relationship (or \textbf{association}) between two sets of data using coordinate points. 

\begin{itemize}
    \item \textbf{Positive Association:} As $x$ increases, $y$ increases. (The dots go uphill).
    \item \textbf{Negative Association:} As $x$ increases, $y$ decreases. (The dots go downhill).
    \item \textbf{No Association:} The dots are scattered everywhere with no pattern.
    \item \textbf{Linear vs. Non-Linear:} Does the pattern look like a straight line or a curve?
    \item \textbf{Outliers:} A point that is far away from the main cluster of data.
\end{itemize}

\vspace{4mm}

\medskip
\begin{itemize}
    \item \textbf{Pattern:} This is a \textbf{strong, positive, linear} association.
    \item \textbf{Meaning:} As the temperature goes up, ice cream sales go up.

\end{itemize}

\begin{tcolorbox}[colback=customteal!20]
\large\textcolor{black}{\textbf{Describing Associations}}
\end{tcolorbox}

\noindent
When describing a scatter plot, use three words: Strength (Strong/Weak), Direction (Positive/Negative/None), and Shape (Linear/Non-Linear).

\vspace{3mm}

\begin{tcolorbox}[colback=white, colframe=black!25, boxrule=0.6pt, arc=4mm, left=6mm, right=6mm, top=5mm, bottom=5mm]

\textbf{Worked Example 1: Real-World Meaning}

\medskip

\textbf{Problem:} Describe the expected association between the "Age of a Used Car" ($x$-axis) and the "Value of the Car" ($y$-axis).

\medskip

\textbf{Solution:}
\begin{itemize}
    \item Think about how the variables relate. As a car gets older (age increases), its value usually drops (value decreases).
    \item \textbf{Direction:} Negative association.
    \item \textbf{Shape:} It might be non-linear (loses value fast at first, then slows down).
    \item \textbf{Strength:} It would be a strong association, as age is a major factor in car pricing.
\end{itemize}

\end{tcolorbox}
